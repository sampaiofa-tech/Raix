# Brief para Designer — Pacote Grafico RAIX

## Objetivo

Produzir o material visual do manual do usuario do RAIX (Android e Desktop) para distribuicao digital (PDF, imagens para WhatsApp, redes sociais).

---

## Identidade visual

### Paleta de cores

| Token | Hex | Uso |
|---|---|---|
| Background | `#0B1325` | Fundo principal |
| Surface | `#1E2432` | Cards, paineis, barras |
| TextPrimary | `#F5F7FA` | Texto principal |
| TextSecondary | `#8A93A6` | Texto secundario, legendas |
| ActionPrimary | `#00E676` | Botoes, acoes, links |
| Gold | `#D4AF37` | Destaques premium |
| Error | `#E5484D` | Alertas, erros |

### Tipografia

- **Titulos:** Inter Medium
- **Corpo:** Inter Regular
- **Codigo/tecnico:** JetBrains Mono

### Tom visual

- Escuro, moderno, premium
- Sem excesso de elementos decorativos
- Transmitir confianca, sobriedade e seguranca
- Sem emojis

---

## Pecas necessarias

### 1. Manual do usuario (PDF)

- **Formato:** A4 vertical, digital (PDF interativo)
- **Paginas estimadas:** 12-16 (Android) + 12-16 (Desktop)
- **Conteudo:** texto das 11 secoes (fornecido em `conteudo-manual-android.md` e `conteudo-manual-desktop.md`)
- **Capturas de tela:** serao fornecidas na pasta `capturas/` (pendente)
- **Capa:** logo RAIX + tagline "Privacidade forte por design" + versao

### 2. Cards para WhatsApp (imagens)

- **Formato:** 1080x1080px (quadrado) e 1080x1920px (stories)
- **Quantidade:** 5-8 cards por plataforma (Android/Desktop)
- **Conteudo:** 1 card por secao principal (resumo visual + captura)
- **CTA:** "Baixe em raixtech.com" ou "Saiba mais"

### 3. Capa de apresentacao

- **Formato:** 1920x1080px (landscape)
- **Uso:** capa de PDF, banner de site, header de redes sociais
- **Conteudo:** logo + tagline + visual escuro premium

---

## Capturas de tela (a fornecer)

O designer recebera capturas reais do app na pasta `capturas/`. Telas esperadas:

**Android:**
1. Tela de onboarding (frase de recuperacao)
2. Lista de contatos (home)
3. Conversa aberta (mensagem criptografada)
4. QR Code de identidade
5. Tela de configuracoes

**Desktop (Windows):**
1. Layout 3 colunas (rail + lista + conversa)
2. Conversa aberta
3. Identidade / QR Code
4. Mini-janela de notificacao

---

## Restricoes

- **Nenhum dado real** nas capturas (usar contatos ficticios).
- **Nenhum overclaim:** nao usar "100% seguro", "inquebravel", "impossivel de hackear".
- **Linguagem aprovada:** "privacidade forte por design", "criptografia de ponta a ponta", "servidor deposito cego".
- **Sem emojis** em nenhum material.
- **LGPD:** nao incluir dados pessoais reais. Referencia: raixtech.com (PP e ToU).
